# Правила работы с проектом kg_controller

## 1. Режим внесения изменений в код
* **Запрет на самостоятельную модификацию кода**: Запрещено вносить любые изменения в исходный код (C, ASM, SysConfig, скрипты линкера и т.д.) без прямого и явного указания пользователя.
* Любые предложения по коду предварительно обсуждаются и согласовываются с пользователем.

## 2. Режим управления версиями (Git)
* **Запрет на самостоятельные коммиты и пуши**: Запрещено выполнять `git commit` и `git push` без прямого указания пользователя.
* **Комплексный коммит и пуш**: Если пользователь дает прямое указание («закоммить», «залей на гит», «отправь в репозиторий» или аналогичное), необходимо выполнять операцию сразу в оба уровня:
  1. Создать локальный коммит (`git commit`).
  2. Сразу отправить изменения в удаленный репозиторий (`git push origin main`).

## 3. Сборка и верификация
* Среда: Code Composer Studio v11 (`C:\ti\ccs1120`).
* Компилятор: `C:\ti\ccs1120\ccs\tools\compiler\ti-cgt-c2000_21.6.0.LTS`.
* Сборка выполняется вызовом GNU Make в папке `CPU1_FLASH`:
  ```bash
  cd CPU1_FLASH && /c/ti/ccs1120/ccs/utils/bin/gmake all
  ```
